# willkyu's research notes

个人科研笔记，用于整理论文笔记、概念和研究问题。

在线访问：<https://willkyu.github.io/research/>

站点由 [Quartz v5](https://github.com/jackyzha0/quartz) 生成，并通过 GitHub Actions 发布到 GitHub Pages。

## 目录

- `content/index.md`：网站首页
- `content/papers/`：论文笔记
- `content/concepts/`：概念笔记
- `content/templates/`：笔记模板
- `zotero/`：Zotero 同步数据与状态
- `quartz.config.yaml`：网站和插件配置

本知识库通过 [Zotero Sync and Publish](https://github.com/willkyu/zotero-sync-and-publish-plugin) 插件管线自动同步笔记，并构建、发布到 GitHub Pages。
